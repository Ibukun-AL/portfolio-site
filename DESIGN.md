# Design: The Changelog

Career and projects presented as a release log: dense, editorial, dated, scannable. Deliberately unlike Vantage Works (blueprint, navy, orange).

- **Colour:** bone paper #F4F1EA (60), ink #16181D (30), muted #666A72, rule #D8D3C7. One accent, ultramarine #2B3FFF, used only on clickable primary actions (Email me, Send message).
- **Type:** Newsreader (display, headings), Public Sans (body), IBM Plex Mono for versions, dates and stack lines only.
- **Layout:** sticky left column on desktop (name, section list, availability); content as ruled rows on the right. Single column on mobile.
- **Motion:** none beyond 150ms colour transitions on links, so no off switch is needed.
- **Shape:** 0 radius, 1px rules.
